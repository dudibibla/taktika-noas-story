# המסע הנגיש של נועה

אב-טיפוס לתהליך **החלפת משלמים בחשבון המים** (תאגיד המים רמת גן), שתוכנן למשתמשת בת 70 ומעלה.

העיקרון המוביל: **נועה לא ממלאת – נועה מאשרת.** במקום טופס ארוך להקלדה, נועה מצלמת מסמכים, המערכת מחלצת מהם את הנתונים, ונועה מאשרת בלחיצה אחת גדולה. השדה היחיד שמוקלד הוא מספר הטלפון.

## מה יש באב-טיפוס

הדף מציג שלוש נקודות מבט על אותה בקשה, עם מעבר ביניהן בלשוניות בראש המסך:

1. **המסע של נועה (אזרח)** – אשף של שמונה מסכים: פתיחה, מה להכין, תעודת זהות, חוזה שכירות, מונה המים, מי עוד גר בדירה, סיכום ואישור, ומסך מעקב. כפתור "☎️ התקשרו אליי" זמין בכל מסך, וההתקדמות נשמרת בדפדפן.
2. **סביבת הנציג (Back-Office)** – מציג מסמכים, טבלת חריגות, שליחת בקשה להשלמת מסמכים ללקוח.
3. **מרכז שליטה למנהל (Ops Center)** – ניהול משלים ויומן ביקורת (Audit Log).

## הרצה

אין צורך בהתקנה או בשרת. פותחים את `index.html` בדפדפן.

## קבצים

| קובץ | תוכן |
| :--- | :--- |
| `index.html` | מבנה הדף ושלושת המסכים |
| `style.css` | עיצוב (פונט Heebo, ממשק בעברית מימין לשמאל) |
| `app.js` | לוגיקת האשף, סביבת הנציג ומרכז הניהול |
| `אפיון גרסה 2 - תוצר 1_ המסע של נועה.md` | אפיון חווית המשתמש של גרסה 2, מסך אחר מסך |
| `אפיון גרסה 2 - תוצר 4_ מיפוי מול הטופס הבירוקרטי המקורי.md` | מיפוי כל דרישה בטופס המקורי למקום שלה בגרסה 2 |
| `המסע של נועה.pdf` | המצגת לכיתה |

## המיפוי מול הטופס המקורי בקצרה

מתוך 17 הדרישות בטופס של רמת גן:

- **10 מכוסות** מההתחלה.
- **4 תוקנו** אחרי שהמיפוי חשף אותן: טלפון נייד, מספר נכס/צרכן, מספר כרטיס מים ותאריך קריאת המונה.
- **2 שונו במכוון**: מבעל הנכס נאספים רק שם וטלפון, בלי ת"ז; ובמקום חתימה גרפית יש אישור בלחיצה ארוכה.
- **1 מחוץ להיקף**: סוג הבקשה. התרגיל הגדיר מסלול אחד בלבד – התחלת שכירות, נכס פרטי, הגשה עצמאית.

שתי שאלות עדיין פתוחות מול התאגיד: האם אישור בלחיצה מתקבל במקום חתימה מזהה, והאם נדרשת ת"ז של בעל הנכס.
